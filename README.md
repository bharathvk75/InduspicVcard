# INDUSPIC ENGINEERS — Digital VCard

A premium, interactive single-page digital business card for **INDUSPIC ENGINEERS — CHEMICALS DIVISION**.

Built with **React**, **TypeScript**, **Tailwind CSS**, and **GSAP**.

---

## 🚀 Features

- **Single-Screen Viewport Layout**: Optimized for mobile and desktop screens without unwanted scrolling.
- **Industrial Ambient Aesthetic**: Subtle micro-grid overlay and ambient radial glows featuring brand colors (terracotta & olive).
- **Brand Action Buttons**:
  - **Website**: Opens company site with official Induspic logo.
  - **Mail**: Opens email client with official 4-color Gmail logo.
  - **WhatsApp**: Opens WhatsApp chat (+91 9449983601) with official WhatsApp brand logo.
  - **Call**: Opens phone dialer (+91 9449983601) with phone icon.
- **Embedded Map Preview**: Interactive Google Maps preview card with a direct "View on Maps" badge.
- **Contact Details**: Direct dial options for:
  - **Primary**: ANBU SOMAN (+91 9449983601)
  - **Alternative**: BHARATH ABHINESH A (+91 6363447946)
- **Save VCard (.vcf)**: Generates and downloads a `.vcf` contact card directly to phone or computer.
- **GSAP Entrance & Touch Animations**: Fluid Apple-inspired button spring-back micro-interactions.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP (GreenSock)
- **Icons**: Lucide React + Custom Brand SVGs

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd VCARD
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Build for Production

Compile TypeScript and build the optimized distribution bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
